## 1. `UNIX_CLUB/README.md` template

```markdown
# Virtual Clubroom — UNIX_CLUB

> Discover, join and run 42 Portugal's student clubs — and keep them alive across generations.

**Live demo:** https://42clubroom.ensui.dev · **Team:** <names>

![Join a club in 3 clicks](docs/media/join-flow.gif)

## Why
Clubs are hard to find, information is scattered, and clubs disappear when members graduate.
Virtual Clubroom gives every club its own space, makes joining a 3-click flow, and keeps clubs alive
through co-ownership, transfer, archival and revival into new eras.

## Tech stack
- **Backend:** Java 21, Spring Boot 3.5, Spring Modulith (verified modular monolith, transactional outbox events), Spring Security (OAuth2 with 42 + sessions in Redis), JPA + Flyway, WebSocket/STOMP
- **Frontend:** React 19, TypeScript, Vite, TanStack Query, React Router, Tailwind CSS v4 + shadcn/ui, FullCalendar
- **Data and infra:** PostgreSQL 17, Redis 8, SeaweedFS (S3), Docker Compose, nginx, Cloudflare Tunnel, Resend (email)

## Architecture
<!-- one diagram + 5 bullets; link to docs/ -->
13 modules with verified boundaries · events through a Postgres outbox · stateless instances (Redis sessions + WebSocket fan-out) ·
media direct to object storage · read models for the public directory. Full design: `docs/`.

## Run it
### Docker (prod-like)
    cp .env.example .env    # fill FT_CLIENT_ID/SECRET, passwords
    docker compose -f compose.yaml -f compose.prod.yaml --profile demo up -d --build
    # → http://localhost:8080 (set APP_PUBLIC_URL=http://localhost:8080, COOKIE_SECURE=false)

### Development
    docker compose -f compose.yaml -f compose.dev.yaml up -d
    cd backend && ./run-dev.sh            # Spring Boot on :8080
    cd frontend && npm ci && npm run dev  # Vite on :5173
```
