# 05 — API Reference

The authoritative, machine-readable contract is the OpenAPI document generated by springdoc at **`/v3/api-docs`** (Swagger UI at `/swagger-ui.html` in dev). The frontend generates its TypeScript types from it ([08-frontend.md §6](08-frontend.md#6-api-layer)). This page is the human-readable overview.

---

## 1. Conventions

| Topic | Convention |
|-------|-----------|
| Base path | `/api` (REST), `/api/public` (anonymous), `/api/admin` (ROLE_ADMIN), `/ws` (STOMP), `/ical` (token feeds) |
| Format | JSON, UTF-8. Timestamps are ISO-8601 UTC (`2026-10-18T14:03:12.123Z`). IDs are UUID strings (chat message IDs are numbers). |
| Authentication | `SESSION` cookie (HttpOnly, Secure, SameSite=Lax), set by Login with 42 or `POST /api/auth/login`. |
| CSRF | Unsafe methods (`POST`, `PUT`, `PATCH`, `DELETE`) must send header `X-XSRF-TOKEN` = value of cookie `XSRF-TOKEN`. |
| Authorization failures | `401` = not logged in. `403` = logged in but not allowed. `404` = does not exist **or** you may not know it exists (e.g. a pending club you didn't found). |
| Validation | `400` with `code: VALIDATION_FAILED` and `errors[]`. |
| Business rule violation | `422` with a specific `code` (e.g. `CLUB_NOT_ACTIVE`, `LAST_OWNER`). |
| Conflicts | `409` (`ALREADY_MEMBER`, `CONCURRENT_MODIFICATION`, `DUPLICATE`). |
| Pagination: keyset | `?cursor=<opaque>&limit=n` → `{ "items": [...], "nextCursor": "..." \| null }` |
| Pagination: offset | `?page=0&size=20` → `{ "items": [...], "page": 0, "size": 20, "totalElements": 134 }` |
| Idempotency | `PUT`/`DELETE` reactions are idempotent; chat `POST` is idempotent by `clientNonce`; listeners are idempotent server-side. |
| Versioning | Unversioned `/api` = v1. Breaking changes would go to `/api/v2/...` per resource. |

### 1.1 Error format (RFC 9457 problem details)

```json
{
  "type": "about:blank",
  "title": "Unprocessable Entity",
  "status": 422,
  "detail": "A club must keep at least one owner. Invite a co-owner first.",
  "instance": "/api/clubs/7b0c…/owners/me/step-down",
  "code": "LAST_OWNER"
}
```

```json
{
  "type": "about:blank",
  "title": "Bad Request",
  "status": 400,
  "detail": "Invalid request content.",
  "code": "VALIDATION_FAILED",
  "errors": [ { "field": "name", "message": "size must be between 3 and 60" } ]
}
```

## 3. WebSocket (STOMP)

| Item | Value |
|------|-------|
| Endpoint | `wss://<host>/ws` (native WebSocket, no SockJS) |
| Authentication | Existing `SESSION` cookie (handshake). Origin must match `app.realtime.allowed-origins`. |
| Client → server | `CONNECT`, `SUBSCRIBE`, `UNSUBSCRIBE`, `DISCONNECT` only. **`SEND` is rejected** (push-only; use REST). |
| Heartbeat | 10 s / 10 s |

### 3.1 Destinations

| Subscribe to | Authorized when | Message types |
|--------------|-----------------|---------------|
| `/user/queue/notifications` | always (own queue) | `notification.created` |
| `/topic/channels/{channelId}/messages` | can read the CHAT channel | `message.created`, `message.updated`, `message.deleted` |
| `/topic/channels/{channelId}/posts` | can read the FORUM channel | `post.created`, `post.updated`, `post.deleted` |
| `/topic/posts/{postId}` | can read the post's channel | `comment.created`, `comment.deleted`, `reactions.changed` |

### 3.2 Envelope

```json
{
  "type": "message.created",
  "payload": {
    "id": 18342,
    "channelId": "0d4c…",
    "era": 2,
    "author": { "id": "…", "login": "jdoe", "displayName": "Jane Doe", "avatarUrl": "https://cdn.intra.42.fr/…" },
    "body": "See you at 18h!",
    "media": [],
    "clientNonce": "3f1e…",
    "deleted": false,
    "createdAt": "2026-10-18T14:03:12.123Z",
    "editedAt": null
  },
  "sentAt": "2026-10-18T14:03:12.140Z"
}
```

**Delivery is best effort.** On reconnect, clients refetch the active views (TanStack Query invalidation). Pushes never carry viewer-specific fields such as `myReactions`.

| `CLUB_NOT_ACTIVE`, `CLUB_NOT_PENDING`, `CLUB_NOT_ARCHIVED`, `CLUB_NOT_EDITABLE`, `TOO_MANY_PENDING_REQUESTS`, `LAST_OWNER`, `INVITEE_NOT_MEMBER`, `MEMBERSHIP_NOT_ACTIVE`, `SYSTEM_ROLE_IMMUTABLE`, `GROUP_NOT_USABLE`, `GROUP_SYNCED`, `NOT_A_MEMBER`, `WRONG_CHANNEL_TYPE`, `HISTORY_READ_ONLY`, `INVALID_PARENT`, `POST_DELETED`, `NOT_AUTHOR`, `EVENT_CANCELLED`, `REVIVAL_NOT_PENDING`, `MEDIA_KIND_NOT_ALLOWED`, `MEDIA_TOO_LARGE`, `MEDIA_TYPE_NOT_ALLOWED`, `MEDIA_NOT_UPLOADED`, `MEDIA_REJECTED`, `MEDIA_NOT_ATTACHABLE`, `MEDIA_NOT_PENDING` | 422 | Business rules |
